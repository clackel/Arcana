# 请求链路

## Filter

前端发起请求首先被过滤器拦截

### 1.`@WebFilter`注解配置拦截路径

```java
@WebFilter(urlPatterns = "/*")
```

### 2.实现Filter中的doFilter方法

```java
public class TokenFilter implements Filter {
    public void doFilter(ServletRequest servletRequest, ServletResponse servletResponse, FilterChain filterChain){
        # 放行请求
        filterChain.doFilter(request, response);
    }
}
```

## JWT令牌校验

### 1.设置Base64编码密钥

```java
SIGN_KEY = "eXVraXNz";
```

### 2.生成令牌

`Map<String, Object> claims` 需要存入令牌的自定义数据

```java
Jwts.builder()
    .signWith(SignatureAlgorithm.HS256, SIGN_KEY) /* 加密算法，密钥 */
    .addClaims(claims)
    .setExpiration(new Date(System.currentTimeMillis()EXPIRE_TIME)) /* 设置过期时间 */
    .compact();
```

### 3.解析令牌

`@setSigningKey`传入对应的密钥以及令牌,`@getBody`获取claims字段

```java
Jwts.parser()
    .setSigningKey(SIGN_KEY)
    .parseClaimsJws(jwt)
    .getBody();
```

## ThreadLocal

线程存取关键数据，可供一次请求的不同阶段共享数据

### 1.创建线程

线程支持存入数据`.set`、读取数据`.get`和删除线程`.remove`三种操作

```java
public class CurrentHolder {

    private static final ThreadLocal<Integer> CURRENT_LOCAL = new ThreadLocal<>();

    public static void setCurrentId(Integer employeeId) {
        CURRENT_LOCAL.set(employeeId);
    }

    public static Integer getCurrentId() {
        return CURRENT_LOCAL.get();
    }

    public static void remove() {
        CURRENT_LOCAL.remove();
    }
}
```

### 2.读取线程中的数据

在同一个线程的每个地方都可以读写线程里的数据

```java
CurrentHolder.setCurrentId(empId);
CurrentHolder.getCurrentId();
```

## AOP

AOP是一种面向切面的编程思想，实现在不修改源代码的情况下给程序动态统一添加额外功能的一种技术，其应用主要体现在事务处理、日志管理、权限控制、异常处理等方面。

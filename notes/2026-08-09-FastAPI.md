## 知识点一：创建与启动 FastAPI 项目

### 创建应用实例

```python
from fastapi import FastAPI

app = FastAPI()
```

`FastAPI()` 用来创建 Web 应用实例。后续编写的路由、中间件等功能都注册到 `app` 上。

### 启动应用

```bash
uvicorn main:app --reload
```

各部分含义：

| 内容 | 含义 |
| --- | --- |
| `uvicorn` | 运行 FastAPI 应用的 ASGI 服务器 |
| `main` | Python 文件名 `main.py` |
| `app` | `main.py` 中创建的 FastAPI 实例 |
| `--reload` | 修改代码后自动重启，适用于开发环境 |

FastAPI 支持使用 `async def` 定义异步处理函数，适合数据库访问、网络请求等需要等待 I/O 的场景。但写成异步函数并不意味着所有任务都会自动变快。

## 知识点二：路由

路由负责建立“请求地址和处理函数”的对应关系。

```python
@app.get("/")
async def root():
    return {"message": "Hello World"}
```

这段代码包含：

- `app`：FastAPI 应用实例；
- `get`：HTTP 请求方法；
- `/`：请求路径；
- `root()`：处理请求的函数；
- `return`：返回给客户端的数据。

装饰器 `@app.get("/")` 表示：当客户端向 `/` 发送 GET 请求时，执行下方的 `root()` 函数。

今天使用到的请求方法：

| 方法 | 主要用途 |
| --- | --- |
| `GET` | 查询资源 |
| `POST` | 创建资源、提交数据 |
| `PUT` | 更新资源 |

---

## 知识点三：路径参数

路径参数写在 URL 路径内部，通常用来定位某个具体资源。

```python
from fastapi import Path

@app.get("/book/{id}")
async def get_book(
    id: int = Path(
        ...,
        gt=0,
        lt=101,
        description="书籍 id，取值范围为 1～100",
    )
):
    return {"id": id, "title": f"这是第{id}本书"}
```

请求示例：

```text
GET /book/10
```

参数校验含义：

| 写法 | 含义 |
| --- | --- |
| `id: int` | 参数应该是整数 |
| `Path(...)` | 参数来自请求路径，并且必填 |
| `gt=0` | 必须大于 0 |
| `lt=101` | 必须小于 101 |
| `description` | 在接口文档中添加参数说明 |

字符串路径参数可以限制长度：

```python
@app.get("/author/{name}")
async def get_name(
    name: str = Path(..., min_length=2, max_length=100)
):
    return {"name": f"这是{name}的信息"}
```

这里要求 `name` 的长度为 2～100 个字符。

### 当前理解

路径参数是 URL 路径的一部分，适合表示书籍 ID、新闻 ID、用户名等用于定位具体资源的信息。FastAPI 会根据类型注解和 `Path` 中的规则自动完成转换与校验。

## 知识点四：查询参数

查询参数位于 URL 的 `?` 后面，适合分页、筛选和排序。

```python
from fastapi import Query

@app.get("/news/news_list")
async def get_news_list(
    skip: int = Query(0, description="跳过的记录数", ge=0, lt=100),
    limit: int = Query(10, description="返回的记录数", gt=0),
):
    return {"skip": skip, "limit": limit}
```

请求示例：

```text
GET /news/news_list?skip=20&limit=10
```

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `skip` | `0` | 跳过前面多少条记录 |
| `limit` | `10` | 本次返回多少条记录 |

如果请求中没有提供参数，就使用默认值。

### 路径参数与查询参数的区别

| 对比 | 路径参数 | 查询参数 |
| --- | --- | --- |
| 位置 | URL 路径中 | `?` 后面 |
| 示例 | `/book/10` | `/news?skip=0&limit=10` |
| 用途 | 定位具体资源 | 分页、筛选、排序 |

## 知识点五：请求体参数

请求体参数位于 HTTP 请求的消息体中，适合提交结构较复杂的数据，常用于创建或更新资源。

今天通过注册接口接收用户名和密码：

```python
from pydantic import BaseModel, Field


class User(BaseModel):
    username: str = Field(
        default="mizuki",
        min_length=2,
        max_length=10,
        description="用户名，长度要求 2～10 个字符",
    )
    password: str = Field(min_length=3, max_length=10)


@app.post("/register")
async def register(user: User):
    return user
```

处理过程：

1. 创建继承自 `BaseModel` 的数据模型；
2. 为字段添加类型注解；
3. 使用 `Field` 设置默认值、长度和描述；
4. 在路由函数中通过 `user: User` 接收请求体；
5. FastAPI 自动解析并校验客户端提交的 JSON。

请求体示例：

```json
{
  "username": "mizuki",
  "password": "123456"
}
```

### 当前理解

路径参数和查询参数适合传递相对简单的数据；当一个请求需要提交用户名、密码等多个相关字段时，可以定义 Pydantic 模型接收请求体。

### 需要注意

真实项目不能直接返回或记录明文密码。今天的代码用于学习请求体和数据校验，之后实现真实注册功能时需要进行密码哈希处理。

## 知识点六：响应类型

默认情况下，FastAPI 会把返回的 Python 对象转换成 JSON 兼容格式，并封装为 JSON 响应。

除了默认 JSON 响应，也可以指定其他响应类型。

### 返回 HTML

```python
from fastapi.responses import HTMLResponse


@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>这是一级标题</h1>"
```

`response_class=HTMLResponse` 告诉 FastAPI，这个接口返回的是 HTML，而不是普通 JSON。

### 返回文件

```python
from fastapi.responses import FileResponse


@app.get("/file")
async def get_file():
    path = "./files/1.jpg"
    return FileResponse(path)
```

`FileResponse` 可以将指定路径的文件作为 HTTP 响应返回。使用时需要保证文件真实存在，并注意不要让用户任意控制服务器文件路径。

### 两种指定响应的方式

1. 在路由装饰器中通过 `response_class` 指定响应类；
2. 在函数中直接返回一个响应对象，例如 `FileResponse(path)`。

## 知识点七：响应模型

响应模型用于描述和约束接口应该返回的数据结构。

```python
from pydantic import BaseModel


class News(BaseModel):
    id: int
    title: str
    content: str


@app.get("/news/{id}", response_model=News)
async def get_news(id: int):
    return {
        "id": id,
        "title": f"这是第{id}条新闻",
        "content": "这是新闻内容",
    }
```

这里的 `response_model=News` 表示响应应该符合 `News` 模型定义的结构。

它的主要作用包括：

- 校验返回数据；
- 在接口文档中展示响应结构；
- 对输出数据进行转换与过滤；
- 让接口的输入和输出更加明确。

请求体模型描述客户端传入的数据，响应模型描述服务端返回的数据。两者都可以使用 Pydantic 模型，但用途不同。

## 知识点八：异常处理

当请求的资源不存在或业务条件不满足时，可以主动抛出 `HTTPException`。

```python
from fastapi import HTTPException


@app.get("/news/{id}")
async def get_news(id: int):
    if id not in range(1, 10):
        raise HTTPException(
            status_code=404,
            detail="您所查询的新闻不存在",
        )
    return {"id": id}
```

参数含义：

| 参数 | 作用 |
| --- | --- |
| `status_code=404` | 指明 HTTP 状态码，表示资源不存在 |
| `detail=...` | 返回具体错误信息 |

这里必须使用 `raise` 抛出异常，不能只写 `return HTTPException(...)`。

### 当前理解

参数校验错误通常由 FastAPI 自动处理；资源不存在、权限不足等业务错误，则需要开发者根据实际逻辑主动抛出异常。

## 知识点九：中间件

中间件可以在每个请求进入路由函数之前和响应返回客户端之前执行统一逻辑。

常见用途：

- 日志记录；
- 身份认证；
- 性能监控；
- 跨域处理；
- 添加统一响应头。

```python
@app.middleware("http")
async def middleware1(request, call_next):
    print("中间件1 start")
    response = await call_next(request)
    print("中间件1 end")
    return response


@app.middleware("http")
async def middleware2(request, call_next):
    print("中间件2 start")
    response = await call_next(request)
    print("中间件2 end")
    return response
```

本次实验观察到的输出顺序：

```text
中间件2 start
中间件1 start
中间件1 end
中间件2 end
```

可以把它理解成嵌套结构：后注册的中间件先接收到请求，内部中间件处理结束后，响应再按照相反方向返回。

`call_next(request)` 的作用是将请求继续交给下一个中间件或具体路由处理函数。如果不调用它，请求就不会继续进入后续处理过程。

## 知识点十：依赖注入

依赖注入用于提取多个接口共同需要的逻辑，实现代码复用和解耦。

常见使用场景：

- 处理公共请求参数；
- 获取数据库连接；
- 身份认证和权限检查；
- 复用业务前置逻辑。

### 定义公共分页依赖

```python
from fastapi import Depends, Query


async def common_parameters(
    skip: int = Query(0, ge=0),
    limit: int = Query(10, le=60),
):
    return {"skip": skip, "limit": limit}
```

### 在新闻列表中声明依赖

```python
@app.get("/news/news_list")
async def get_news_list(commons=Depends(common_parameters)):
    return commons
```

执行过程可以理解为：

```text
收到请求
→ FastAPI 执行 common_parameters
→ 解析并校验 skip、limit
→ 将返回结果传给 commons
→ 执行 get_news_list
```

这样多个列表接口就不必重复定义相同的分页参数。

## 容易遗忘的内容

- `Path`、`Query`、`Field` 分别用于不同位置或模型中的参数声明；
- `response_class` 控制具体响应类型，`response_model` 描述并约束响应数据结构；
- 主动抛出 HTTP 异常需要使用 `raise HTTPException(...)`；
- 中间件中必须调用并等待 `call_next(request)`，请求才会继续处理；
- `Depends` 接收的是依赖函数本身，一般不要在里面手动加括号调用；
- 查询参数有默认值时，客户端可以不传；路径参数通常必须传递；
- FastAPI 的自动校验来自 Python 类型注解以及 Pydantic/FastAPI 提供的字段约束。
